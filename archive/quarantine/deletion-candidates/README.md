# Deletion Candidates

This directory is currently **empty**. There are no deletion candidates.

Nothing is placed here automatically. An item is only ever moved here as an
explicit, recorded action, and even then **no file is ever deleted without
explicit human confirmation** — the review tool (`archive/review.mjs`) is
read-only and never performs or exposes deletion.
